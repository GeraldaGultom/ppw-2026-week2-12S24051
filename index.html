Portofolio Pribadi (Proyek Ini)

Halaman ini sendiri — dimulai dari HTML/CSS murni di Minggu 2, kini dimodernisasi total menggunakan Bootstrap 5.

Dashboard Monitoring Jaringan

Selama magang di Pertamina Patra Niaga Sumbagut, saya bertanggung jawab mengelola dan membersihkan data jaringan, kemudian memvisualisasikannya menjadi dashboard monitoring yang membantu tim memantau kondisi jaringan secara real-time.

Teknologi: HTML, CSS, JavaScript, Data Visualization

ImunKu — Aplikasi Imunisasi Anak

Proyek UI/UX end-to-end untuk aplikasi pengingat jadwal imunisasi anak. Saya terlibat mulai dari riset kebutuhan pengguna, membuat wireframe dan prototipe di Figma, hingga melakukan usability testing dengan calon pengguna.

Teknologi: Figma, UX Research, Usability Testing

SIIR — Sistem Informasi Izin Ruangan

Sistem informasi yang saya rancang untuk memudahkan mahasiswa melihat ketersediaan ruangan kampus secara real-time, mengajukan izin pemakaian, serta memantau status persetujuan permohonan tersebut.

Fokus: Analisis & Perancangan Sistem

Portofolio Pribadi

Halaman portofolio ini dibangun secara bertahap: Minggu 2 menggunakan HTML5 semantik dan CSS murni, kemudian di Minggu 3 direfaktor menggunakan Bootstrap 5 dengan custom CSS overrides untuk mempertahankan identitas visual pribadi.

Teknologi: HTML5, CSS3, Bootstrap 5, Git, GitHub Pages
